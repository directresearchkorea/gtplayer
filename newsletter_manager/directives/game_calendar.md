# 게임 캘린더 (섹션 1 + 1-B) — SOP

## 목적
매일 발행되는 GTPlayer 뉴스레터의 섹션 1(게임 캘린더) + 섹션 1-B(글로벌 이벤트)를 자동으로 생성한다.

## 입력
- RSS/스크래핑으로 수집된 통합 뉴스 후보 리스트 (JSON)
- `sent_log.db` — 과거 발송 이력
- `events_calendar.json` — 글로벌 게임 이벤트 정적 DB

## 도구
- `execution/collect_news.py` — 데이터 수집
- `execution/curate_calendar.py` — LLM 선별 + 번역

## 섹션 1: 게임 캘린더 사양
- **범위**: 오늘 + 내일 (D-Day ~ D+1)
- **항목 수**: 6건 내외 (한국/인도/일본 각 최소 1건, 나머지 유동)
- **카테고리**: release / update / event
- **링크**: 뉴스 기사 URL (공식 홈페이지 X)
- **언어**: 한국어, English, 日本語

### 데이터 소스
| 국가 | 소스 | 방법 |
|---|---|---|
| 🇰🇷 | 인벤 캘린더, 게임메카, 디스이즈게임 | 스크래핑/RSS |
| 🇮🇳 | IGN India, Gamer Tweak, AFK Gaming | RSS/스크래핑 |
| 🇯🇵 | 4Gamer, Famitsu, Dengeki | RSS/스크래핑 |
| 🌍 | Steam API, PlayStation Blog | API/RSS |

### LLM 선별 기준
1. 교차 출현 (2곳 이상 → 가중치)
2. 조회수/댓글수 높은 것 우선
3. 어제 발송 목록과 중복 맥락 제외
4. 국가별 최소 1건 보장

## 섹션 1-B: 글로벌 게임 이벤트 사양
- **범위**: 향후 3~6개월
- **조건**: 있을 때만 표시 (없으면 생략)
- **항목 수**: 1~3건
- **소스**: `events_calendar.json` (정적 DB)
- D-day 카운트다운 표시
- 관련 기사 링크 매칭

## 출력
- 구조화된 JSON (섹션 1 + 섹션 1-B)
- 3개 언어 (ko/en/ja)

## 엣지 케이스
- 특정 국가에서 오늘/내일 뉴스가 없으면: 해당 국가 건수를 0으로 하고 다른 국가로 채움
- RSS 피드 접근 실패: 해당 소스 건너뛰고 나머지로 진행, 로그에 경고 기록
- 이벤트 DB에 3~6개월 내 행사 없으면: 섹션 1-B 전체 생략
