# 게임 브리핑 (섹션 2) — SOP

## 목적
매일 발행되는 GTPlayer 뉴스레터의 섹션 2(게임 브리핑)를 자동으로 생성한다.
섹션 1(캘린더)이 일정 기반이라면, 섹션 2는 이슈/뉴스 기반이다.

## 입력
- RSS/스크래핑으로 수집된 통합 뉴스 후보 리스트 (JSON)
- `sent_log.db` — 과거 발송 이력
- 섹션 1에서 이미 선정된 뉴스 목록 (중복 방지용)

## 도구
- `execution/collect_news.py` — 데이터 수집 (섹션 1과 공유)
- `execution/curate_briefing.py` — LLM 선별 + 번역

## 사양
- **초점**: 최근 24시간 내 보도된 이슈/뉴스
- **항목 수**: 6~7건
- **배분**: 한국/인도/일본 각 최소 1건 유동 배분 + 글로벌 뉴스 추가 (최대 1~2건)
- **포맷**: 한줄 요약 (30자 이내) + 기사 링크
- **카테고리**: discount / issue / personnel / release / update
- **언어**: 한국어, English, 日本語

### 데이터 소스
섹션 1과 동일 9개 소스 + 글로벌 추가:
| 소스 | 역할 |
|---|---|
| IGN (글로벌) | 글로벌 이슈 |
| PC Gamer | PC 게임 할인, 업계 동향 |
| GamesIndustry.biz | 인사이동, M&A, 실적 |

### LLM 선별 기준
1. 교차 출현 (2곳 이상 → 가중치)
2. 조회수/댓글수 높은 것 우선
3. 어제 발송 + 오늘 캘린더 섹션과 중복 제외
4. 국가별 최소 1건 보장 + 글로벌 추가

## 출력
- 구조화된 JSON
- 3개 언어 (ko/en/ja)

## 엣지 케이스
- 글로벌 뉴스가 없으면: 한국/인도/일본 뉴스로만 6~7건 채움
- 특정 국가 뉴스 부족: 다른 국가 + 글로벌로 보충
- 섹션 1과 동일 주제: LLM 프롬프트에서 교차 필터로 제외
