# 인스타그램 인게이지먼트 자동화 디렉티브 (Playwright 버전)

> 마지막 업데이트: 2026-07-28

## 개요
인스타그램의 비공식 API 차단을 우회하기 위해, 실제 브라우저(Edge)를 제어하여 시드(Seed) 계정의 팔로워 중 비공개 계정을 제외한 게이머 계정들을 동적으로 탐색하고 안전하게 팔로우하는 SOP입니다.

---

## 작업 스크립트 가이드

**목적:** Playwright 브라우저를 통한 자연스러운 최근 게시물 좋아요 및 팔로우 수행  
**데이터 소스:** `sns_manager/execution/instagram_targets.json`  
**라이브러리:** `playwright` (Chromium/Edge)  

### 실행 방법

#### 1. 최초 1회 브라우저 로그인 세션 빌드
스크립트를 실행하면 PC에 Edge 브라우저 창이 뜹니다. 수동으로 로그인을 진행하여 메인 홈 피드 화면까지 띄운 뒤, 터미널 창에서 [엔터] 키를 누르면 세션 쿠키가 저장됩니다.
```bash
py sns_manager/execution/instagram_browser_login.py
```
*(세션이 인스타그램 서버에 의해 차단되거나 만료되는 경우 이 로그인 스크립트를 재실행해 주어야 합니다.)*

#### 2. 안전한 테스트 작동 확인 (클릭 생략)
실제 팔로우 버튼을 누르거나 대기하지 않고, 타겟을 추출하고 비공개 계정을 정상적으로 감지/필터링하는지만 로깅합니다.
```bash
py sns_manager/execution/instagram_browser_automator.py --test
```

#### 3. 실제 자동화 실행
```bash
py sns_manager/execution/instagram_browser_automator.py
```

### 설정 관리 (`instagram_targets.json`)
- `seed_accounts`: 타겟 탐색의 기준이 되는 계정 (예: "glitch_zine", "playstation_korea")

---

## ⚠️ 브라우저 우회 자동화의 안전 가이드

실제 브라우저를 제어하더라도 인스타그램의 보안 알고리즘은 계정의 비정상적 트래픽을 감시합니다.

1. **Headed 모드 전용 구동:**
   - 봇 탐지율을 낮추기 위해 `headless=False` 상태로 동작합니다. 실행 시 Edge 브라우저 창이 뜨는 것이 정상이므로 창을 강제로 닫지 마십시오.
2. **일일 최대 작업량 제한:**
   - 한 번 실행 시 **최대 5개의 계정**에만 작업을 수행하고 안전하게 종료됩니다.
   - 각 계정 방문 시 비공개 계정이 아니라면 **최근 1개의 게시물에 좋아요**를 누른 뒤 팔로우를 진행합니다.
3. **넉넉한 랜덤 딜레이(Delay):**
   - 인위적으로 **3분 ~ 5분(180~300초)**의 긴 대기 시간을 주어 사람의 행동 패턴을 흉내 냅니다.
4. **로컬 기록을 통한 중복 방지:**
   - 이미 한 번 팔로우한 유저는 `instagram_followed.json`에 영구 기록되며, 스크립트 실행 시 API 호출 없이 이 리스트를 먼저 검사하여 건너뜁니다.
